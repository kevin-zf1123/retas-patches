# Stylos 插件管理器 0.2

解压本包，退出 Stylos，运行 StylosPluginManager.exe 并选择原版 Stylos 2.6.0 x86 程序。初次运行的插件列表为空。在 **从安装包安装…** 中选择 DevKit 插件 ZIP，点击 **应用更改**，再启动 Stylos。0.2.1 支持一次选择多个插件；混选时会跳过开发工具包和管理器 ZIP 并显示文件名。单独选择管理器 ZIP 仍可更新管理器。相同 ID 的新包可更新已有安装。停用保留包，卸载移除它的模块、受管文件和地址占用。备份保存实际导入的 ZIP 和启用状态。

每个插件包包含自己的实现和 schema 3 清单。加载器在 Stylos 启动时读取启用模块清单；插件可以提供消息处理、画布显示和环境设置页。管理器和插件分别构建。第三方只需分发一个符合 DevKit 约定的 ZIP。

## 从 0.1.x 迁移

退出 Stylos，从解压目录运行 **新版** 管理器并选择原安装的 Stylos.exe。确认迁移，选择已安装组件对应的 0.2 完整插件包，可以一次多选。管理器读取该目录中原管理器的安装记录，检查替换包，备份旧包，并在一次文件事务内保留已安装插件及其启停状态。缺少某个替换包时会指出具体 ID。额外选中的包可在迁移后通过“从安装包安装…”另行添加。原来的画布偏好继续生效。

旧格式的备份由旧版管理器读取。0.2 的单插件及全量备份包含实际包字节和启用状态，恢复时会验证 SHA-256。使用“卸载管理器…”会先制作当前插件备份，再恢复原版宿主。日常更新 0.2 管理器可使用“从包更新管理器…”。

命令行也调用相同的包管理和事务实现。常用形式为 `--setup 目录`、`--install 目录 插件.zip`、`--list 目录`、`--disable|--enable|--uninstall 目录 插件ID`、`--backup 目录 备份.zip [插件ID]`、`--restore 目录 备份.zip` 和 `--migrate 目录 完整包1.zip 完整包2.zip`。
