# 指针中心滚轮缩放

用滚轮查看局部时，鼠标指向的画稿位置会尽量留在指针下。插件支持旋转、镜像后的画布，也会累计高精度滚轮的小幅滚动。

1. 在管理器中导入 `Stylos-Mousewheel-Zoom-x86.zip`，应用并重开 Stylos。[下载组件](../../packages/Stylos-Mousewheel-Zoom-x86.zip)
2. 点击要查看的画布，将指针停在一个清楚的细节上，例如两条线的交点。松开 Ctrl、Shift 和鼠标按键，直接滚动滚轮。
3. 向前滚一格放大 **5 个百分点**，向后滚一格缩小 **5 个百分点**。例如从 100% 放大一格到 105%；可用范围约为 10% 至 1000%。

若滚轮没有按此方式缩放，确认指针落在当前活动画布的绘图区内。画布以外的列表、工具面板以及带 Ctrl 或 Shift 的滚动由原控件处理。此组件可独立停用，旋转快捷键有自己的开关。
