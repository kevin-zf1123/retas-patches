# 画布显示

画稿缩小或旋转后，斜线和细线的边缘可能出现台阶。画布显示插件提供三种缩放插值方式，切换效果只影响屏幕预览，画稿像素和导出文件保持原样。

1. 导入 `Stylos-Better-Canvas-Display-x86.zip`，应用后重开 Stylos。渲染模块需要支持 SSE2 的处理器。
2. 打开一张有斜线的画稿，缩放到平常作画的倍率。进入 **编辑 → 设置 → 环境设置 → 插件 → 画布显示**。
3. 在 **缩放插值** 中选择一种方式，点外层窗口的 **确定**，回到同一画面比较。点 **取消** 可放弃本次修改。

| 选项 | 观察效果 |
|---|---|
| 原始缩放 | 使用 Stylos 原有显示方式，可作为对照。 |
| 双线性 | 默认方式，相邻像素间过渡较平滑。 |
| 双立方 | 线稿边缘通常更清晰，可和双线性对照选择。 |

找不到该设置页时，检查管理器里“画布显示”是否为“已启用”，并确认已经应用更改、重新启动了所选安装目录里的 Stylos。
