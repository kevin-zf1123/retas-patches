# 运动检查与后台预渲染

1. 使用 0.2.0 管理器导入 `Stylos-Motion-Check-x86.zip`。保存画稿并退出 Stylos，点 **应用更改**。
2. 重开 Stylos，打开已保存的摄影表和画稿。空闲约两秒后，任务管理器中可见一个 `StylosRender64.exe`。它在后台用多个线程准备帧，完成后自行退出。
3. 照常执行运动检查。Stylos 会读入匹配的预渲染帧，尚未准备好的画面在播放时计算。保存的画稿或显示设置发生变化后，受影响的帧需要重新准备。自动保存可以保持开启。

后台程序需要能运行 Windows x64 程序的系统或 CrossOver 容器。打开画稿、按键、声音和播放窗口均由前台 Stylos 处理。磁盘缓存位于 `%LOCALAPPDATA%\StylosMotionRender`。默认上限为 8 GiB，超出上限时优先清理较旧的帧。需要关闭后台工作时，在管理器里停用该组件并应用。

## 动检预渲染设置

在 **环境设置 → 插件 → 动检预渲染** 中设置线程数（0 为自动）、开始前的空闲时间、后台进程内存上限和磁盘缓存上限。默认空闲时间为 2 秒，内存上限为 1024 MiB。选择 **指定文件夹** 可更换缓存位置，页面会显示所选磁盘的可用空间。新帧写入该文件夹内的 `StylosMotionRender` 子目录。点击 **确定** 保存，**取消** 放弃本次修改。
