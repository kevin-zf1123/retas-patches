# 运动检查与后台预渲染

播放较长的摄影表时，插件会利用空闲时间提前渲染画面并缓存结果。先保存摄影表和画稿，后台进程才能读取当前版本。

1. 导入 `Stylos-Motion-Check-x86.zip`，应用后重开 Stylos。[下载组件](../../packages/Stylos-Motion-Check-x86.zip)
2. 打开已保存的 `.sxf` 摄影表，停下操作约两秒。后台有工作时，任务管理器中可见 `StylosRenderA.exe` 和 `StylosRenderB.exe`。继续操作或修改文件可能使本轮预渲染停止，下一次空闲时再开始。
3. 照常执行 Stylos 的运动检查。已经准备好的帧可从缓存读取，未准备好的帧在播放时计算。修改并保存画稿后，受影响的画面需要重新准备。

**预渲染完成后会响吗？** 完成路径会退出后台进程；启用调试跟踪时还会写入 `complete`。插件没有安排完成提示音。

磁盘缓存位于 `%LOCALAPPDATA%\StylosMotionRender`。超过约 512 MiB 时会回收到约 448 MiB。需要关闭后台工作时，保存并退出 Stylos，在管理器中停用本组件并应用。管理器会一并移除这套安装目录中的两个渲染程序。
