# 高 DPI 界面

在高分屏上，如果 Stylos 的菜单和工具按钮太小，可以让 Windows 按桌面缩放比例放大整个界面。此组件适用于注册表支持的 **中文 4 GiB 基线**。这里的 4 GiB 指主程序的寻址标记，与电脑安装的内存容量无关。

1. 在插件管理器中导入 `Stylos-High-DPI-x86.zip`，应用更改并重开 Stylos。[下载组件](../../packages/Stylos-High-DPI-x86.zip)
2. 在 Windows **设置 → 系统 → 显示** 查看当前屏幕的缩放比例。比例高于 100% 时，对照菜单文字、工具按钮和对话框的大小；在 100% 下变化可能不明显。
3. Windows 放大整个界面后，文字边缘可能显得柔和。如果只想放大局部画稿，可以使用[滚轮缩放](mousewheel-zoom.md)。

若管理器提示基线不支持高 DPI，请停用这一项再应用其余组件。要恢复原有界面大小，在管理器中停用“高 DPI 界面”并重启 Stylos。
