# 中割对位

在透光台上，插件按指定的中割比把旋转、缩放和平移分配给两张原画。第一行是起点，第二行是终点。当前中割画纸留在原位置，两张参考图的显示变换随对位调整。使用两张未镜像的二维参考图。

## 按比例对位

1. 从管理器导入 `Stylos-Inbetween-x86.zip`，应用后重开 Stylos。
2. 打开中割画纸，把起始和结束原画按顺序登记到当前透光台组。组内条目多于两张时，只选中待处理的两张。
3. 用透光台工具把对应特征对齐，再执行 **透光台 → 位置调节 → 移动图像到中间位置**。默认快捷键为 **Ctrl+Alt+Shift+I**；若已占用，在快捷键设置里查看实际绑定。
4. 选择 **1/2** 可做正中割；**1/3** 更靠近起点。点 **▼** 展开后可输入其他分数，例如 **2/5**，再点 **应用**。分母支持 1 至 10000，分子支持 0 至分母。

## 四点自动对位

在比例面板展开 **▼**，选好比例，点 **四点自动对位…**。先在起始原画点两个容易辨认、相距较远的特征，例如眼角和衣领尖，再在结束原画按相同顺序点对应位置。点错时可右键撤回上一点。

第四点松开后进入预览。在 **透光台图层** 中选要修正的原画，拖动实心红点微调。按 **Enter**、双击画布或点 **确定** 可以接受结果；按 **Esc** 或点 **取消** 可以回到拾取前的状态。

## 调整工作习惯

进入 **编辑 → 设置 → 环境设置 → 插件 → 中割对位**，可注册常用比例、直接执行 1/2、每次点选四点或跳过预览。比例面板优先显示登记列表的前三项，外层点 **确定** 后保存。

支持的 Stylos 2.6 中文版可以显示小数角度和倍率。两张参考图相差 1° 时，正中割会分别显示 −0.5° 和 +0.5°，开关精确倍率比均可。原生数值框和保存格式仍使用整数，重新载入透光台后会恢复为整数值。
