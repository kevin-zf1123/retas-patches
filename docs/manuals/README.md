# Stylos 插件使用手册

适用于 Windows 版 Stylos 2.6.0 x86。可按要完成的工作选择组件，每个组件都能在插件管理器里单独启停。

| 要完成的工作 | 使用手册 |
|---|---|
| 放大高分屏上的菜单、按钮和文字 | [高 DPI 界面](high-dpi.md) |
| 为摄影表播放提前准备画面 | [运动检查与后台预渲染](motion-check.md) |
| 调整缩放画布时线条的显示效果 | [画布显示](anti-alias.md) |
| 按中割比对齐两张旋转或缩放过的参考图 | [中割对位](inbetween.md) |
| 用原生 WinTab 驱动修正笔尖落点 | [原生数位板坐标修正](tablet-native.md) |
| 用 Windows Ink 输入笔迹和笔压 | [Windows Ink 笔输入](windows-ink.md) |
| 旋转视图，把预览器选中的多张图登记到透光台 | [旋转快捷键与预览器登记](rotation-shortcuts.md) |
| 以鼠标指针下的画面为中心缩放 | [滚轮缩放](mousewheel-zoom.md) |

## 安装和停用

1. 首次安装前，打开并退出一次 Stylos，以生成快捷键配置。解压管理器 ZIP 到单独文件夹，运行 `StylosPluginManager.exe`，选择日常使用的 `Stylos.exe`。[下载插件管理器](../../packages/Stylos-Plugin-Manager-x86.zip)
2. 在管理器中点 **从安装包安装…**，选择对应手册列出的组件 ZIP，再点 **应用更改**。若已打开 Stylos，先保存画稿并正常退出，等管理器完成写入后重新启动。
3. 以后可从 **编辑 → 设置 → 插件管理器…** 查看版本和状态。临时关闭某项功能时，选中该行，点 **停用 → 应用更改**。重新使用时点 **启用**。点 **卸载** 会移除该组件的安装记录。

右键已安装的组件可以单独备份。“备份全部插件”也会收录已停用的组件。全量恢复会替换插件列表，单插件恢复只更新该项及其互斥项。个人快捷键和绘图偏好保存在当前 Windows 用户配置中。[管理器更新、备份与卸载说明](../../plugin-manager/stylos/README.md)
