# Stylos 中割对位补丁（32 位 Windows）

当前合集请使用 [插件页版中割安装包](../../packages/Stylos-Inbetween-x86.zip)。在 **环境设置 → 插件 → 中割对位** 直接编辑参数。下文中“注册中割比…”按钮是原发布版 v0.1 的入口。

[中文](README.zh-CN.md) · [English](README.md) · [日本語](README.ja.md)

补丁扩展了“透光台 → 位置调节 → 移动图像到中间位置”。两张原画对齐后，可以按指定中割比分配它们之间的旋转、缩放和平移，让两张参考图在中割位置重合，当前中割画纸保持原位。支持两张未镜像的二维参考图。可以沿用透光台工具手动对齐，也可以在每张原画上各点两个对应特征，快速完成对齐。

## 安装与使用

1. 关闭 Stylos，先备份**这台电脑当前使用的 Stylos.exe**，尤其是已经改过的公司版本。首次使用时先打开并退出一次 Stylos，让它生成快捷键配置。
2. 解压后双击 **StylosInbetween.exe**，选择安装目录中的 **Stylos.exe**，确认原位更新。以后照常从任务栏或开始菜单中固定的快捷方式启动。每台电脑都选择自己的主程序，沿用本机插件。安装器需要 .NET Framework 4.5 或更高版本，以及安装目录的写权限。
3. 打开中割画纸，在透光台从上到下登记起始原画、结束原画，手动对位时，先用原有的透光台操作对齐两个对应特征。若透光台里有更多条目，只选中要处理的两张。
4. 按安装器显示的快捷键（默认 **Ctrl+Alt+Shift+I**），点 **1/2**、**2/3** 或 **1/3** 即可执行对位。初始默认选中 **1/2**，按回车即可正中割。第一行原画代表起点，第二行代表终点。
5. 点 **▼** 可展开输入框。输入其他分数（例如 **2/5**），或从下拉列表选择已注册的比例，然后点“应用”。按 Esc 可关闭窗口。分母范围为 1 至 10000，分子可以从 0 取到分母。

### 在画布上点四个点自动对位

在透光台中按起点、终点的顺序放好两张参考图，选择当前画纸使用的透光台组。开始前可以缩放或平移画布，让两个特征都在视野内。按中割快捷键，点 **▼**，输入或选择进度，再点 **四点自动对位…**。输入框初始为 1/2。

1. 画布先显示起始参考图。在图上点第一个特征，再点第二个特征。两点分得越开，选点误差对角度的影响越小。
2. 透光台切换到结束参考图。按同样顺序点两个对应特征。第四次松开鼠标时，两张参考图按指定的中割比对齐，进入预览。
3. 拾取时右键或点“上一步”可撤回一点，“移动提示窗”可让出被遮挡的位置。按 Esc 或点“取消”会恢复参考图原有的显示状态，保留原来的位置、倍率和角度。

在 **对位预览** 面板的 **透光台图层** 列表中选起始原画或结束原画。两张图同时显示，画布上的两个实心红点标出所选参考图的两个特征位置，圆心就是拖动锚点。按住一个红点拖动，两张图会按原中割比实时旋转、缩放和平移。另外三个源特征保持原样。拖动期间会多出两个浅红点。一个随鼠标表示你在所选图上修正的位置，一个标出另一张图的对应位置。两者都以按下鼠标那一刻的图层变换为参照。实红点显示当前对齐结果，松手后保留实红点。可以切换图层继续修正。

**双击画布、按 Enter 或点“确定”** 保留结果。按 Esc 或点“取消”会恢复到四点拾取以前的状态。若希望第四点松开就直接应用，到 **环境设置 → 注册中割比…** 勾选 **四点对位后跳过预览**。

取点使用当前画布的原生坐标转换，支持参考图已有位移、旋转和缩放。程序在拾取期间依次显示所选两张参考图，结束后恢复各参考图的可见性及透明度。实际写回使用 Stylos 的整数倍率与整数角度。两段特征连线的中点会重合；长度比或角度无法精确表示时，两端会留下对称的偏差。

在 **环境设置 → 注册中割比…** 勾选 **每次对位前点选四个特征点**，快捷面板上的每个比例按钮都会启动四点拾取。同时勾选 **直接执行 1/2，不显示比例窗口**，按快捷键就直接在画布上点四个点，按正中割应用。

### 在环境设置中注册中割比

打开 **编辑 → 设置 → 环境设置**，点击左下角的 **注册中割比…**。在列表旁输入分数，点“添加”即可登记。选中列表项可以更改或删除，“恢复默认”会恢复三个初始比例。快捷面板按登记顺序显示前三项，展开后的列表包含全部已注册比例。等值分数会合并为同一个比例。

勾选 **直接执行 1/2，不显示比例窗口**，以后触发中割命令就会直接正中割。在同一处取消勾选即可恢复比例窗口。**锁定两张参考图的精确倍率比** 同时适用于两种模式。比例编辑窗口和外层环境设置都点“确定”，修改才会保存到当前 Windows 用户的配置中。外层点“取消”会丢弃这次修改。

安装器会把键位合并进当前用户的 Stylos 原生 `shortcut.rac`。若 I 已被占用，会按顺序尝试同一组修饰键加 J、K、U、O。“移动图像到中间位置”仍可在 Stylos 快捷键设置里重新绑定。如需还原主程序，关闭 Stylos 后将本机备份放回原路径。

## 缩放、旋转与取整

设第一行到第二行的相对变换为 T，进度为 t。两行的目标变换分别是 T^t 和 T^(t−1)，倍率按 k^t 插值。角度沿较短方向旋转，恰好 180° 时保留输入方向。位置使用以各自纸心为原点的物理坐标，命令只调整参考图的显示变换。

Stylos 以整数百分比保存 5% 至 1600% 的倍率，以整数度保存角度。两行使用相同的角度取整偏差。默认优先接近指定进度，如果每行在一个百分点内就能保持原倍率比，则采用那对整数倍率。程序根据实际写入的倍率和角度补偿平移，使第一张原画的纸心与其对应点对齐。

手动对位后，如果必须保持两处特征同时重合，在环境设置中勾选 **锁定两张参考图的精确倍率比**。程序会选取保持原倍率比且最接近目标的整数倍率组合。这可能改变实际运动进度，例如 147% 和 100% 只能以 147 和 100 的整数倍维持精确比例。若在起点或终点无法同时满足恒等变换和比例锁定，程序会在写入前提示。

## 兼容性与构建

安装器从本机程序识别已注册的中点命令、两级分派、两行选择逻辑、数值写入函数、导入函数、刷新和返回路径，在安装目录中准备好新文件，再原子替换 Stylos.exe。重复运行会识别已安装的版本，必要时补全快捷键。支持采用这一实现布局、未签名且无重定位表的 PE32 Stylos 2.6。如果命令实现、文件布局不匹配，或已安装无法识别的中割补丁，安装器会提示原因。已发布的英文分数窗口版、中文快捷比例版、四点对位版和十字控制点预览版都可在校验旧命令代码、绑定关系及入口后原位升级。其他键位和可兼容的本机主程序改动会保留。

从仓库根目录执行 `python3 stylos/rotation-scale-inbetween/build.py dist/stylos/rotation-scale-inbetween` 可重新构建。构建依赖 Python 3、Clang/LLVM、LLD、MinGW-w64 windres 和 Mono mcs。插值使用标量 x86 和 x87。独立的 `check.c` 使用螺旋中心公式核对结果，通过 Windows 线程周期计数器测量一次求出两行变换的开销。
