# Stylos 2.6.0 中割对位

在管理器中导入 Stylos-Inbetween-x86.zip，应用后重新启动 Stylos。首次使用前先打开并退出一次 Stylos 以生成快捷键配置。默认快捷键为 Ctrl+Alt+Shift+I，冲突时依次尝试 J、K、U、O。

打开 **编辑 → 设置 → 环境设置 → 插件 → 中割对位**，在右侧编辑已注册的比例、直接执行 1/2、精确倍率比、四点拾取和跳过预览。与画布补丁共装时，旁边还会出现“画布显示”。外层“确定”保存，“取消”放弃草稿。迁移旧版请按管理器文档先备份并恢复原版宿主。

支持的 Stylos 2.6 中文版可以显示小数角度和倍率。两张参考图相差 1° 时，正中割会分别显示 −0.5° 和 +0.5°，开关精确倍率比均可。原生数值框和保存格式仍使用整数，重新载入透光台后会恢复为整数值。
