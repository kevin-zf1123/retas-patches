# Stylos 中割りの位置合わせパッチ（32 ビット Windows 版）

[現行のインストーラー](../../packages/Stylos-Inbetween-x86.zip)では、環境設定の「プラグイン」配下で中割りの設定を編集します。以下のボタンの説明は従来の v0.1 に対応します。

[中文](README.zh-CN.md) · [English](README.md) · [日本語](README.ja.md)

ライトテーブルの中間位置合わせコマンドを拡張します。前後の原画を合わせておくと、指定した中割りの比率に応じて回転・拡縮・移動を両方の原画に振り分け、動画用紙を動かさずに中割りの位置で原画を重ねられます。対象は反転していない 2 枚の 2D 参考画像です。原画同士はライトテーブルで手動で合わせることも、対応する特徴を各原画で 2 点ずつ指定してすばやく合わせることもできます。以下の太字の中国語は、パッチの画面に表示される項目です。

## インストール

1. 初めて Stylos を使う場合は、一度起動して終了し、ショートカット設定を作成します。**使用中の Stylos.exe をバックアップしてください。** すでにカスタマイズしている場合は、その状態のファイルを保存します。
2. 配布 ZIP を展開して `StylosInbetween.exe` を起動し、インストール先の `Stylos.exe` を選びます。インストール先への書き込み権限と .NET Framework 4.5 以降が必要です。
3. 確認すると主プログラムが同じパスで更新されます。タスクバーやスタートメニューのショートカットから、従来どおり Stylos を起動できます。元に戻すときは、Stylos を終了してバックアップを元の場所に戻します。

各 PC のインストール先で個別にパッチを適用してください。インストーラは、そのユーザーの `shortcut.rac` にキー割り当てを追加します。既定は **Ctrl+Alt+Shift+I** です。使用中の場合は同じ修飾キーと J、K、U、O の空いている組み合わせを順に探します。完了画面に表示されるキーを使ってください。

## 中割りの比率を選ぶ

動画用紙を開き、ライトテーブルに始点の原画、終点の原画の順で登録します。参考画像が 3 枚以上ある場合は、対象の 2 枚だけを選びます。手動で位置合わせする場合は、先にライトテーブル上で対応する特徴が重なるように調整しておきます。

ショートカットを押すと、既定で **1/2、2/3、1/3** が表示されます。ボタンを押すとその比率で実行し、初期設定では Enter で 1/2 を実行できます。**▼** を押すと、登録済みの比率を選ぶか、**2/5** などの分数を入力できます。分母は 1～10000、分子は 0～分母の範囲です。**应用** で適用、Esc でキャンセルします。

## キャンバスで 4 点を指定する

1. 現在の用紙で対象のライトテーブルセットを選び、特徴が見える位置・表示倍率にしておきます。ショートカット → **▼** の順に押し、比率を入力して **四点自动对位…** を選びます。
2. 始点の原画が表示されます。異なる特徴を 2 点クリックしてください。2 点の間隔が広いほど、クリック位置のずれによる角度の誤差が小さくなります。
3. 終点の原画に切り替わったら、対応する特徴を同じ順に 2 点クリックします。4 点目で位置合わせのプレビューに移ります。点を打ち直すには右クリックまたは **上一步** を使います。**移动提示窗** で案内ウィンドウを移動できます。

**对位预览** の一覧で修正したい原画を選ぶと、キャンバス上の 2 個の赤い点がその原画の特徴を示します。点をドラッグすると、選んだ特徴の位置を修正しながら、指定した中割りの比率で両方の原画がリアルタイムに回転・拡縮・移動します。残り 3 個の元の特徴点は固定されます。ドラッグ中の薄い赤の 2 点は、動かしている特徴ともう一方の原画の対応点を、ドラッグ開始時の各原画の座標で示します。濃い赤の点は現在の位置合わせの結果です。ボタンを離すと薄い点が消え、引き続き調整できます。

キャンバスをダブルクリックするか、Enter または **确定** で確定します。Esc または **取消** で、4 点を指定する前の状態に戻ります。点を指定している間は参考画像を 1 枚ずつ表示し、終了時には元の表示状態と不透明度に戻します。

## 環境設定

**编辑 → 设置 → 环境设置** の左下にある **注册中割比…** を開きます。分数の追加、変更、削除ができ、**恢复默认** で初期の 3 項目に戻せます。登録順の最初の 3 件がボタンになり、全件をドロップダウンから選べます。等しい分数は同じ比率として扱います。

- **直接执行 1/2，不显示比例窗口** は比率選択を省略して、常に 1/2 で実行します。
- **每次对位前点选四个特征点** は毎回キャンバス上で 4 点を指定します。上の設定と併用すれば、ショートカットから正中割りの点指定に直接入れます。
- **四点对位后跳过预览** はプレビューを省略し、4 点目で適用します。
- **锁定两张参考图的精确倍率比** は、両方の参考画像の倍率比を固定します。

比率の編集画面と親の環境設定画面の両方で **确定** を押すと、現在の Windows ユーザーの設定に保存されます。親画面でキャンセルすると、その回の変更を取り消せます。

## 計算と互換性

始点から終点への相似変換を T、中割りの進度を t とすると、2 枚の目標変換は T^t と T^(t−1) です。倍率 k は k^t で補間し、回転は短い向きを通ります。ちょうど 180 度では入力の符号を保ちます。座標は各用紙の中心を基準とした物理単位です。操作の対象はライトテーブルでの表示変換です。

Stylos が保存できる倍率は整数で 5～1600%、角度は整数度です。手動で合わせた原画では、各倍率の差が目標から 1 ポイント以内なら、元の倍率比を保つ組み合わせを優先します。倍率比の固定を選ぶと、正確な比率を保てる整数値の中から目標に最も近い組み合わせを使います。例えば 147% と 100% の比率を正確に保てるのは 147 と 100 の整数倍に限られます。端点を等倍に保つ条件と倍率比を同時に満たせない場合は、適用前に通知します。4 点合わせでは、丸めた後も 2 本の線分の中点が一致しますが、表現できない長さや角度では両端に対称なずれが残ることがあります。

対応対象は、パッチが識別できる実装を持つ、署名なし・再配置テーブルなしの PE32 形式の Stylos 2.6 です。インストーラはコマンドの登録・分岐、座標や倍率を書き込む関数、画面更新と復帰経路を検証します。再実行時には適用済みの版を認識し、必要に応じてショートカットを修復します。

## ビルド

リポジトリのルートで次のコマンドを実行します。Python 3、Clang/LLVM、LLD、MinGW-w64 と Mono の mcs が必要です。

```sh
python3 stylos/rotation-scale-inbetween/build.py dist/stylos/rotation-scale-inbetween
```

出力先に `Stylos-Inbetween-x86.zip` が生成されます。補間処理は x86 のスカラー命令と x87 を使います。`check.c` では計算結果の検証と Windows 上での実行サイクル計測ができます。
