## 中文

**适用版本：本补丁仅面向本次开发和测试使用的 Windows 32 位 Stylos 2.6.0。** 其他版本的兼容性需由使用者自行确认。如程序布局不同，请修改源码并重新构建后再使用。

v0.1 发布了适用于 **32 位 Windows 版 RETAS STUDIO Stylos 2.6.0** 的旋转缩放中割对位补丁。在透光台上对齐前后两张原画，当前中割画纸保持原位。

- **四点对位**：在起始原画上点两个特征，再在结束原画上按相同顺序点对应位置。可选 **1/2、2/3、1/3**，也可输入或注册自己的中割比。
- **实时修点**：在预览面板中选中原画，拖动画布上的实红点，两张参考图会按原中割比同步更新。拖动时的两个浅红点标出正在修正的特征及其在另一张图上的对应点。双击或按 Enter 确认，Esc 恢复。
- **安装**：下载下方的 `Stylos-Inbetween-x86.zip`。关闭 Stylos，备份当前使用的 `Stylos.exe`，解压并运行 `StylosInbetween.exe`。安装器原位更新主程序，默认快捷键为 **Ctrl+Alt+Shift+I**。
- **兼容性**：安装器需要 .NET Framework 4.5 或更高版本，并会校验本机主程序布局。已在原生 Windows 和 macOS CrossOver 上验证。Stylos 以整数百分比和整数度保存变换，部分比例或角度会有取整误差。

## English

**Supported version: this patch targets only the 32-bit Windows build of Stylos 2.6.0 used for development and testing.** For any other version, verify compatibility yourself. If the executable layout differs, adapt the source and rebuild the patch before use.

v0.1 introduces light-table inbetween alignment for **RETAS STUDIO Stylos 2.6.0 for 32-bit Windows**. It distributes rotation, scale and translation between two key drawings while the active inbetween sheet stays in place.

- **Four-point alignment.** Pick two features on the start drawing and the two matching features on the end drawing in the same order. Choose **1/2, 2/3 or 1/3**, enter a fraction, or register your own ratios.
- **Live adjustment.** Select a drawing in the preview panel and drag a solid red dot. Both references update at the chosen fraction. Two pale red dots identify the feature being corrected and its counterpart on the other drawing. Double-click or press Enter to confirm, or Escape to restore.
- **Install.** Download `Stylos-Inbetween-x86.zip` below. Close Stylos, back up your current `Stylos.exe`, extract the ZIP and run `StylosInbetween.exe`. The installer updates the executable in place. The default shortcut is **Ctrl+Alt+Shift+I**.
- **Compatibility.** The installer requires .NET Framework 4.5 or later and verifies the local executable layout. The patch has been tested on native Windows and macOS CrossOver. Stylos rounds transforms to whole percentage points and degrees. The patch UI is in Simplified Chinese.

## 日本語

**対象バージョンは、今回の開発・検証に使用した 32 ビット Windows 版 Stylos 2.6.0 に限ります。** 他のバージョンに適用する場合は、ご自身で互換性を確認してください。実行ファイルの構造が異なる場合は、ソースコードを修正して再ビルドしてからご使用ください。

v0.1 は **32 ビット Windows 版 RETAS STUDIO Stylos 2.6.0** 向けの中割り位置合わせパッチです。ライトテーブルの前後の原画に回転・拡縮・移動を振り分け、編集中の動画用紙は元の位置に保ちます。

- **4 点で位置合わせ。** 始点の原画で 2 点、終点の原画で対応する 2 点を同じ順にクリックします。中割りの比率は **1/2、2/3、1/3** から選べます。任意の分数の入力や、よく使う比率の登録もできます。
- **リアルタイム調整。** プレビューで原画を選び、キャンバス上の濃い赤の点をドラッグすると、指定した比率で両方の原画が動きます。薄い赤の 2 点は、修正中の特徴点と、もう一方の原画にある対応点を示します。ダブルクリックまたは Enter で確定し、Esc で元に戻せます。
- **インストール。** 下の `Stylos-Inbetween-x86.zip` をダウンロードします。Stylos を終了して使用中の `Stylos.exe` をバックアップし、ZIP を展開して `StylosInbetween.exe` を起動してください。元のパスのまま更新され、既定のショートカットは **Ctrl+Alt+Shift+I** です。
- **対応環境。** インストーラには .NET Framework 4.5 以降が必要です。適用前に実行ファイルの構造を確認します。Windows 実機と macOS の CrossOver で動作確認済みです。Stylos の倍率は整数パーセント、角度は整数度で保存されるため、丸め誤差が生じる場合があります。パッチの画面表示は簡体字中国語です。
