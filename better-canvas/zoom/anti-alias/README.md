# Stylos 2.6.0 画布显示

在 Stylos 插件管理器中导入 Stylos-Better-Canvas-Display-x86.zip，再点击“应用更改”。渲染模块需要 SSE2。

在 **编辑 → 设置 → 环境设置 → 插件 → 画布显示** 选择原始缩放、双线性或双立方。默认双线性；双立方在线稿边缘更清晰。选择其他分类仍会保留未确认的选项，点击外层“确定”后刷新并记住。画布过滤仅影响显示。与中割补丁同时安装时，同一树下还会显示 **中割对位**；原有“插件”分类仍可打开。

在同一管理器里可以停用、重新启用或卸载画布显示。

构建入口是本目录 build.py。需要 Zig 0.13.0、Python 3、pefile、LIEF、本机 .NET Framework csc 和中割 v0.1 参考安装器。完整发行构建所需的基线及参数见 plugin-manager/stylos/README.md。
