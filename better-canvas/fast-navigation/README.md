# Stylos 快速导航

使用 0.2 或更高版本的 Stylos 插件管理器，导入 `Stylos-Fast-Navigation-x86.zip`，点击“应用更改”，再启动 Stylos。

在 **编辑 → 设置 → 环境设置 → 插件 → 快速导航** 勾选或取消“旋转或缩放画布时使用快速预览”，点击外层“确定”立即生效。首次启用默认勾选，已有实验版设置会沿用。也可以在管理器选中“快速导航”，点击“打开设置”。

单独使用时，操作中显示原生预览，停稳后使用双线性插值；关闭开关会恢复原生显示。同时启用“画布显示”时，停稳后的画质遵循其插值设置。管理器中停用或卸载组件后，设置页随之隐藏，下次启用时保留用户的选择。
