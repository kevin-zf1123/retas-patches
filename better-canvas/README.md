# Better Canvas

| 组件 | 作用 | 安装包 |
|---|---|---|
| [rotation-shortcuts/](rotation-shortcuts/) | 旋转按钮、可配置快捷键、预览器登记 | [旋转快捷键](../packages/Stylos-Rotation-Shortcuts-x86.zip) |
| [zoom/mousewheel-zoom/](zoom/mousewheel-zoom/) | 指针中心滚轮，每格 5 个百分点 | [滚轮缩放](../packages/Stylos-Mousewheel-Zoom-x86.zip) |
| [zoom/anti-alias/](zoom/anti-alias/) | 环境设置中的双线性与双立方显示 | [画布显示](../packages/Stylos-Better-Canvas-Display-x86.zip) |

前两项可在管理器中独立安装与启停，宿主通过 CanvasInput.c 分派输入。开发工具和外部客户使用 retas-devkit/ 的版本化接口。原生数位板与 Windows Ink 为另外的可选输入方案。
